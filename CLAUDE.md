## Project Overview

Elden Ring Build Randomizer — a static SPA that generates randomized equipment loadouts for Elden Ring (base game + Shadow of the Erdtree DLC). Deployed to GitHub Pages at `/EldenRingBuildRandomizer/`.

## Commands

- `pnpm dev` — start Vite dev server
- `pnpm build` — type-check with `tsc -b` then build with Vite
- `pnpm lint` — lint with oxlint (`oxlint ./src`)
- `pnpm format` — format with oxfmt (`oxfmt ./src`)
- `pnpm format:check` — check formatting without writing
- `pnpm generate-data` — regenerate `src/data/*.json` from `data/` source files via `tsx scripts/generate-slim-data.ts`

No test framework is configured.

## Architecture

### Data Pipeline

Two-tier data system:

1. **Source data** (`data/base-game/`, `data/dlc/`) — raw JSON keyed by item name with full attributes. Not shipped to the browser.
2. **Slim data** (`src/data/*.json`) — generated by `scripts/generate-slim-data.ts`. Stripped to only the fields the app needs (name, category, weight, etc.). These are the files imported at runtime.

The generate script merges base game and DLC items, normalizes DLC category names to base-game singular form (e.g. "Axes" -> "Axe"), splits armaments into weapons/shields/catalysts by category, and sorts alphabetically.

Item images are mapped via `data/image-map.json` (loaded lazily at runtime).

### Build Codec

Builds are serialized to a compact binary format (version-tagged, base64url-encoded) and stored in the `?build=` query parameter. This enables shareable URLs — the entire build state lives in the URL with no backend. See `src/lib/build-codec.ts`.

### Routing

Single-route app using TanStack Router. The index route validates a `?build=` search param. If absent or invalid, a random build is generated and the URL is replaced. The `basepath` is set from `import.meta.env.BASE_URL` to handle the GitHub Pages subpath.

### UI

- **Tailwind CSS v4** with a custom dark theme defined in `src/index.css` using `@theme` (gold/dark palette inspired by the game's aesthetic)
- **Cinzel** display font for headings, **Inter** for body text
- Components use category-specific CSS classes (`cat-weapon`, `cat-armor`, etc.) for gradient backgrounds on item icons
- `ItemSlot` has three variants: `standard` (weapons/armor), `compact` (ashes/spells), `talisman` (square grid)
- Fixed bottom `ActionBar` with Randomize and Share buttons

### Key Types

- `Build` (`src/types/build.ts`) — all fields are indices into the corresponding data arrays
- Item types (`src/types/items.ts`) — `Weapon`, `Shield`, `Catalyst`, `ArmorPiece`, `Talisman`, `Spell`, `AshOfWar`

- **Formatter**: oxfmt (not Prettier)
- **Linter**: oxlint (not ESLint)
- **Styling**: Tailwind CSS v4 with `@tailwindcss/vite` plugin
- **UI library**: Base UI (`@base-ui/react`) for unstyled primitives

## Deployment

Push to `main` triggers GitHub Actions (`.github/workflows/deploy.yml`) which builds and deploys to GitHub Pages. Vite sets `base: "/EldenRingBuildRandomizer/"` in production mode.
